UPLOAD TO YOUR EXISTING GITHUB WEBSITE
1. Extract Bhusal-Family-Website-v4.zip.
2. Open your bhusal-family.github.io repository on GitHub.
3. Stay in the folder containing the current index.html. Choose Add file >
   Upload files.
4. Upload the extracted CONTENTS below. Do not upload the ZIP itself or an
   enclosing Bhusal-Family folder. Replace the old files with the same names:

   index.html
   styles.css
   app.js
   data.js
   content.js
   community.js
   UPLOAD-GUIDE.txt
   .nojekyll
   photos/README.txt
   documents/Bhusal-Full-Chronicle.pdf
   documents/chronicle-preview.png

5. Upload the documents folder with BOTH files inside it. The website expects
   the PDF at documents/Bhusal-Full-Chronicle.pdf. Uploading it only at the
   repository's top level will not make the new tab work.
6. Keep any existing photos you have added. If you edited photo paths, names or
   stories on GitHub since the previous edition, keep a copy before replacing
   data.js or content.js, then reapply those edits.
7. Enter “Refine family website and add complete PDF” and commit the upload.
8. Wait for GitHub Pages to finish publishing in the Actions tab.
9. Open https://bhusal-family.github.io/ and refresh.
   Mac: Command+Shift+R. Windows: Ctrl+Shift+R.
10. Check the tree, पूर्ण वंशावली, PDF खोल्नुहोस्, and अनुरोध on phone and laptop.

YOUR ADDRESS AND HOSTING DO NOT CHANGE
Use the same repository and Pages settings. No purchased domain is required.

IF .nojekyll IS HIDDEN
The ZIP contains this file. In Finder press Command+Shift+Period to show it.
If your repository already has .nojekyll, leave it there. Otherwise use GitHub's
Add file > Create new file, name it .nojekyll, and commit it.

THE FULL CHRONICLE PDF
The पूर्ण वंशावली tab shows a preview and provides Open PDF and Download buttons.
The PDF contains all current branches from Musu, ten generation columns, spouse
names, and bookmarks for major branches. Daughters have muted red dotted branch
lines. Sons have solid green lines; unknown gender uses gray. A neutral trunk
connects siblings, with each child's final connector showing its own style.

It is ONE large vector page. Open it in the browser's PDF reader or a PDF app,
then zoom in and scroll. In readers that support bookmarks, choose a named
branch to jump there. A4 printing will make the names too small; use the file
digitally for now. The picture on the website is only a preview; use the PDF
for sharp letters at higher zoom. This PDF is a snapshot, not a live export.

FAMILY INFORMATION AND CORRECTIONS
The family data remains the current spreadsheet-based version. Unclear names
and relationships still need family confirmation; ? marks are retained.
The editable Bhusal-Family-Register-v3.xlsx remains your current master. This
design update does not require a new workbook. Keep person IDs stable when
editing. Return the updated workbook when you want both website and PDF rebuilt.
Editing Excel alone does not update either the website or this PDF.

The website's fatherDetails and motherDetails fields hold additional parent
information for spouses when those parents are not separately represented in
the family tree. Existing father details preserve their recorded wording,
including places where supplied. Mother names have not been guessed.

Do not upload the original workbook or paper photograph as part of this update.
Private phone numbers are excluded from this package. Keep future notes,
stories, photos and PDFs free of phone numbers as well.
