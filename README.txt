SHARED PROFILE PHOTOGRAPHS

Place JPG, JPEG, PNG or WebP photographs here. Use filenames such as musu.jpg.
In data.js, find the person's unique id and set the existing photo field:
"photo": "./photos/musu.jpg"
Upload the image and updated data.js to GitHub. Use matching capitalization.

The Add photo button saves only a browser preview. It does not upload images.
Remove any browser preview to see the shared photo. Keep the same photo path
in the Excel master so it can be retained when the website data is refreshed.
